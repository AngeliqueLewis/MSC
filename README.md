# Metro Sisters Circle🌟
Welcome to Metro Sisters Circle, a dynamic tennis community of over 200 ladies in the metro-area. A community for women by women to connect, empower, and uplift one another. Our mission is to create a supportive space where women of all backgrounds can get access to Tennis whether they want to play professionally or for a fun new hobby. If you are looking for a local tennis club, Metro Sisters Circle is here for you.

🚀 Features
Event Calendar: Stay up-to-date on upcoming networking events, workshops, and social gatherings.

Discussion Forums: Engage in thoughtful discussions on topics ranging from career advice to wellness.

Coaches: Access coaches to help you along your tennis journey.

Membership Portal: Become a member to gain access to exclusive content and special perks.

🛠️ Technologies Used
Frontend: Built with HTML, CSS, and JavaScript to ensure a sleek and user-friendly experience.

Backend: Powered by Node.js and Express for efficient handling of user requests and data.

Database: MongoDB for seamless storage of member profiles, events, and forum discussions.

Authentication: Secure user authentication and profile management using JWT.
